প্রিভিউ দেখুন

কিভাবে ওয়েবসাইট আপডেট করবেন

  1. বাম পাশের মেনু থেকে যা বদলাতে চান তা পরিবর্তন করুন। প্রতিটি পরিবর্তন এই ব্রাউজারে নিজে থেকে সংরক্ষিত হয়।
  2. “প্রিভিউ দেখুন” চেপে ওয়েবসাইট কেমন দেখাচ্ছে যাচাই করুন।
  3. “data.js ডাউনলোড” চাপুন। ডাউনলোড হওয়া ফাইলটি দিয়ে GitHub রিপোজিটরির js/data.js ফাইলটি রিপ্লেস করুন।
  4. GitHub-এ Commit করুন। Netlify কয়েক সেকেন্ডের মধ্যে ওয়েবসাইট নতুন করে প্রকাশ করবে।

ভর্তির আবেদন দেখা

ওয়েবসাইট থেকে জমা পড়া ভর্তির আবেদন Netlify ড্যাশবোর্ড থেকে Forms ট্যাবে দেখা যাবে। নতুন আবেদনের ইমেইল পেতে README ফাইলের নির্দেশনা অনুসরণ করুন।

অপ্রকাশিত পরিবর্তন বাতিল

এই ব্রাউজারে যেসব পরিবর্তন করেছেন তা মুছে প্রকাশিত তথ্যে ফিরে যেতে চাইলে নিচের বোতাম চাপুন।

প্রতিষ্ঠানের তথ্য ও যোগাযোগ

ম্যাপে ভুল জায়গা দেখালে “ম্যাপে খোঁজার শব্দ” বদলে আপনার সেন্টারের এলাকার নাম লিখুন।

হোম পেজের প্রধান লেখা

নিচের তালিকায় তথ্য যোগ, বদলানো বা মুছতে পারবেন।

অ্যাডমিন পাসওয়ার্ড বদলান

পাসওয়ার্ড বদলানোর পর data.js ডাউনলোড করে ওয়েবসাইটে আপলোড করুন, তাহলে অন্য ব্রাউজারেও নতুন পাসওয়ার্ড কাজ করবে।

# Student Care - কোচিং সেন্টারের ওয়েবসাইট

একটি সম্পূর্ণ স্ট্যাটিক ওয়েবসাইট (HTML, CSS, JavaScript)। GitHub-এ রেখে Netlify-এ লাইভ করা যাবে।

## ফাইল কাঠামো

```
student-care/
├── index.html        → পাবলিক ওয়েবসাইট (হোম পেজ)
├── admin.html        → অ্যাডমিন প্যানেল (শুধু আপনি ব্যবহার করবেন)
├── css/
│   ├── style.css     → ওয়েবসাইটের ডিজাইন ও অ্যানিমেশন
│   └── admin.css     → অ্যাডমিন প্যানেলের ডিজাইন
└── js/
    ├── data.js       → সব তথ্য (নাম, ঠিকানা, শিক্ষক, কোর্স ইত্যাদি)
    ├── main.js       → ওয়েবসাইটের কার্যকারিতা (টাইমার, তালিকা, ফর্ম)
    └── admin.js      → অ্যাডমিন প্যানেলের কার্যকারিতা
```

## ওয়েবসাইটে যা আছে

- **হিরো সেকশন**: অ্যানিমেটেড শিরোনাম ও আজকের পড়ার অগ্রগতির কার্ড
- **পরিসংখ্যান**: সংখ্যাগুলো স্ক্রল করলে গুনে দেখাবে
- **আমাদের কথা** ও **সুবিধাসমূহ**
- **কোর্সসমূহ**: এসএসসি, এইচএসসি, ভর্তি পরীক্ষা, জুনিয়র ব্যাচ
- **শিক্ষকদের তথ্য ও ছবি**: ছবি না থাকলে নামের প্রথম অক্ষর দিয়ে প্রোফাইল দেখাবে
- **মনোযোগ টুলস** (শিক্ষার্থীদের জন্য):
  - ২৫ / ৪৫ / ৫০ মিনিটের ফোকাস টাইমার, শেষ হলে শব্দ ও বার্তা
  - আজকের পড়ার তালিকা (প্রতিটি ব্রাউজারে আলাদা করে সংরক্ষিত হয়)
  - ঘুরে ঘুরে আসা অনুপ্রেরণার বাক্য
- **ভর্তির আবেদন ফর্ম** (Netlify Forms দিয়ে কাজ করে)
- **ঠিকানা ও যোগাযোগ**: Google Maps, ফোন, ইমেইল, খোলার সময়
- **WhatsApp বাটন**: WhatsApp নম্বর দিলে স্বয়ংক্রিয়ভাবে দেখাবে

## ১. নিজের কম্পিউটারে দেখুন

- `index.html` ফাইলে ডাবল-ক্লিক করে ওয়েবসাইট দেখুন।
- কিছু ফিচার (যেমন ভর্তির ফর্ম জমা) শুধু লাইভ সাইটে কাজ করে।
- VS Code ব্যবহার করলে "Live Server" এক্সটেনশন দিয়ে চালালে ভালো হয়।

## ২. GitHub-এ আপলোড করুন

1. [github.com](https://github.com)-এ অ্যাকাউন্ট খুলুন ও লগইন করুন।
2. উপরের **+** → **New repository** → নাম দিন `student-care` → **Public** → **Create repository**।
3. **uploading an existing file** লিংকে ক্লিক করুন।
4. `student-care` ফোল্ডারের **ভিতরের** সব ফাইল ও ফোল্ডার (`index.html`, `admin.html`, `css`, `js`, `README.md`) টেনে আনুন।
5. নিচে **Commit changes** চাপুন।

## ৩. Netlify-এ লাইভ করুন

1. [netlify.com](https://netlify.com)-এ GitHub অ্যাকাউন্ট দিয়ে সাইন আপ করুন।
2. **Add new site** → **Import an existing project** → **GitHub** → `student-care` রিপোজিটরি সিলেক্ট করুন।
3. **Build command** এবং **Publish directory** খালি রেখে **Deploy** চাপুন।
4. কিছুক্ষণের মধ্যে একটি লিংক পাবেন (যেমন `xyz.netlify.app`)। সেটাই আপনার লাইভ ওয়েবসাইট।
5. চাইলে **Site configuration** → **Change site name** থেকে সুন্দর একটি নাম দিন।

### ভর্তির আবেদনের ইমেইল নোটিফিকেশন চালু করুন

1. Netlify-এ আপনার সাইট খুলুন → **Site configuration** → **Forms** → **Form notifications**।
2. **Add notification** → **Email notification** → **Form submission** সিলেক্ট করুন।
3. যে ইমেইলে আবেদনের খবর চান তা লিখে সেভ করুন।

এরপর কেউ ভর্তির ফর্ম জমা দিলে আপনার ইমেইলে সাথে সাথে খবর যাবে। সব আবেদন Netlify-এর **Forms** ট্যাবেও দেখা যাবে।

> GitHub Pages-এ ভর্তির ফর্ম কাজ করবে না। ফর্ম চালাতে Netlify ব্যবহার করুন।

## ৪. অ্যাডমিন প্যানেল ব্যবহার

অ্যাডমিন প্যানেল খুলুন: `https://আপনার-সাইট.netlify.app/admin.html`

**প্রথমবার:** একটি পাসওয়ার্ড তৈরি করুন (কমপক্ষে ৬ অক্ষর)।

**কিভাবে আপডেট করবেন:**

1. বাম মেনু থেকে যা বদলাতে চান (সেন্টারের তথ্য, শিক্ষক, কোর্স, সুবিধা, পরিসংখ্যান ইত্যাদি) সেখানে যান।
2. পরিবর্তন করে **সংরক্ষণ** চাপুন। এটি এই ব্রাউজারে জমা থাকে।
3. **প্রিভিউ দেখুন** বাটনে ক্লিক করে ওয়েবসাইট কেমন দেখাচ্ছে যাচাই করুন।
4. **data.js ডাউনলোড** চাপুন।
5. GitHub-এ রিপোজিটরি খুলুন → `js` ফোল্ডার → `data.js` → পেন্সিল আইকন (Edit) বা **Upload files** দিয়ে নতুন ফাইলটি দিয়ে পুরনোটি রিপ্লেস করে **Commit changes** করুন।
6. Netlify কয়েক সেকেন্ডের মধ্যে সাইট নতুন করে প্রকাশ করবে।

### গুরুত্বপূর্ণ কথা

- অ্যাডমিন প্যানেলের পরিবর্তন **যে ব্রাউজারে করেছেন শুধু সেখানেই** জমা থাকে। ওয়েবসাইটে দেখাতে অবশ্যই `data.js` ডাউনলোড করে GitHub-এ আপলোড করতে হবে।
- এক ডিভাইসে কাজ করার পর অন্য ডিভাইসে কাজ করতে চাইলে, GitHub-এর `data.js` ফাইলটিই সবচেয়ে সাম্প্রতিক সংস্করণ হওয়া উচিত।
- শিক্ষকের ছবি আপলোড করলে সেটি নিজে থেকে ছোট করে নেওয়া হয়। অনেক বেশি ছবি দিলে ব্রাউজারের জায়গা ভরে যেতে পারে, তাই ছবিগুলো GitHub-এর `images` ফোল্ডারে রেখে সেখানকার পথ (যেমন `images/teacher-1.jpg`) লিখে দেওয়াই ভালো।
- ছবির পথ দিতে চাইলে GitHub-এ `images` নামে একটি ফোল্ডার বানিয়ে ছবি আপলোড করুন।

## ৫. নিরাপত্তা সম্পর্কে

- অ্যাডমিন পাসওয়ার্ড পাসওয়ার্ডের হ্যাশ হিসেবে `data.js`-এ থাকে, সাধারণ টেক্সট হিসেবে নয়।
- তবে এটি একটি স্ট্যাটিক সাইট, তাই এটি ব্যাংক-লেভেলের নিরাপত্তা নয়। `admin.html` লিংক কাউকে শেয়ার করবেন না।
- আরও শক্ত নিরাপত্তা চাইলে Netlify-এর **Visitor access** (Password protection) বা **Netlify Identity** ব্যবহার করতে পারেন।

## ৬. যা আগে বদলে নিতে হবে

`js/data.js` ফাইল বা অ্যাডমিন প্যানেল থেকে এই তথ্যগুলো নিজের মতো করে বসান:

- **সেন্টারের তথ্য**: ফোন নম্বর, WhatsApp নম্বর (যেমন `8801XXXXXXXXX`), ইমেইল, খোলার সময়, ঠিকানা
- **ম্যাপ**: "ম্যাপে খোঁজার শব্দ" এ আপনার সেন্টারের এলাকা লিখুন, যাতে সঠিক জায়গা দেখায়
- **পরিসংখ্যান**: "১২০০+ সফল শিক্ষার্থী" ইত্যাদি সংখ্যাগুলো আপনার আসল তথ্য দিয়ে বদলান
- **শিক্ষকদের তথ্য ও ছবি**: উদাহরণের নামগুলো বদলে আপনার শিক্ষকদের নাম ও ছবি দিন
- **কোর্স ও বিবরণ**: আপনার সেন্টারে যে কোর্সগুলো আছে সেগুলো রাখুন

## ৭. ডিজাইন বদলানো

- রং বদলাতে `css/style.css`-এর উপরের `:root` অংশে থাকা রংগুলো (যেমন `--marigold`, `--teal-900`) বদলান।
- ফন্ট বদলাতে `index.html` ও `admin.html`-এর Google Fonts লিংক এবং CSS-এর `font-family` বদলান।
